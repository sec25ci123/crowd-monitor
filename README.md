
# SentraPulse 🚨

### AI-Based Real-Time Crowd Density Prediction and Safety Alert System

SentraPulse is an AI-powered crowd monitoring prototype designed to detect people, estimate crowd density and generate safety alerts.

## Features

- Upload crowd videos
- Live mobile camera monitoring
- Front and rear camera selection
- YOLO-based person detection
- Automatic people counting
- Crowd density estimation
- Low, Moderate, High and Critical risk levels
- Dashboard safety alerts
- Telegram notifications

## Technologies

- Python
- Streamlit
- YOLO
- OpenCV
- Streamlit-WebRTC

## Deployment

Streamlit Community Cloud

## Project Purpose

To support early identification of potentially dangerous crowd conditions and improve crowd safety monitoring.
